# Shahlan Mourad – Portfolio

My personal portfolio site, live at **https://shahlan-mourad.github.io**.

## Tech

- Plain HTML, CSS and JavaScript – no build step for the page itself
- Bootstrap 5, Bootstrap Icons, Font Awesome and Swiper from CDN (pinned versions)
- The contact form is sent through [FormSubmit](https://formsubmit.co)

## GitHub data

Skills and projects come from `data/github.json`. The file is generated by
`scripts/update-github-data.mjs`, so visitors never call the GitHub API
(it allows only 60 requests per hour without a token). Repos to hide are listed
in that script. The file is not committed.

## Run locally

Requires Node and the GitHub CLI (`gh`):

```bash
GITHUB_TOKEN=$(gh auth token) node scripts/update-github-data.mjs
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

The workflow in `.github/workflows/deploy.yml` builds `data/github.json` and
publishes the site to GitHub Pages on every push to `main`, once a day and on
demand. In the repo settings, Pages must use **GitHub Actions** as its source.
