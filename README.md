# Shahlan Mourad – Portfolio

My personal portfolio site, live at **https://shahlan-mourad.github.io**.

## Tech

- Plain HTML, CSS and JavaScript – no framework and no build step for the page itself
- All content is written in `index.html`, so the page works without JavaScript and search engines see everything
- Icons are one local SVG sprite (`assets/icons.svg`) from Simple Icons (CC0), Devicon (MIT) and Bootstrap Icons (MIT)
- Font: Inter from Google Fonts
- The contact form is sent through [FormSubmit](https://formsubmit.co)

## Editing content

| What | Where |
| --- | --- |
| Text, experience, skills | `index.html` |
| Selected projects | `index.html`, section `#projects` (one `<article>` per project) |
| Project screenshots | `assets/projects/` – see the comment above `#projects` in `index.html` |
| CV | `assets/Shahlan-Mourad-CV.pdf` (the "Download CV" button links here) |
| Link preview image | `assets/og-image.png` (1200 × 630) |

## "More on GitHub"

Below the selected projects, the site lists other public repos from `data/github.json`.
The file is generated by `scripts/update-github-data.mjs`, so visitors never call the
GitHub API (it allows only 60 requests per hour without a token). Repos to hide are
listed in that script, and repos already shown as cards are listed in `FEATURED_REPOS`
in `script.js`. The file is not committed.

## Run locally

Requires Node and the GitHub CLI (`gh`). Use a local server – the icon sprite does not load from `file://`.

```bash
GITHUB_TOKEN=$(gh auth token) node scripts/update-github-data.mjs
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

The workflow in `.github/workflows/deploy.yml` builds `data/github.json` and
publishes the site to GitHub Pages on every push to `main`, once a day and on
demand. In the repo settings, Pages must use **GitHub Actions** as its source.
